# Photos des équipes

Dépose ici les photos/affiches des équipes (une image par équipe).

Deux façons de relier une photo à une équipe :

1. **Automatique (recommandé)** — nomme le fichier d'après le nom de l'équipe,
   en minuscules, sans accents, espaces/apostrophes remplacés par des tirets,
   extension `.jpg`. Exemples (édition 2026) :
   - « Un indien dans l'Île »        → `un-indien-dans-l-ile.jpg`
   - « L'ayeuture c'est l'aventure » → `l-ayeuture-c-est-l-aventure.jpg`
   - « Les petits jaunes »           → `les-petits-jaunes.jpg`
   - « Les grappes en folie »        → `les-grappes-en-folie.jpg`

2. **Explicite** — dans l'onglet `Equipes` du Google Sheet, colonne `photo`,
   mets soit `equipes/mon-fichier.jpg`, soit une URL complète `https://…`.

Conseil : images carrées ou paysage, légères (< 500 Ko). Sans photo, l'équipe
s'affiche simplement sans image (aucun bug).
