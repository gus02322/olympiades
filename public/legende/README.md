# Photos des équipes championnes

Dépose ici les photos des anciens vainqueurs (une image par édition).

- Formats conseillés : `.jpg` ou `.png`, idéalement carrées (ex. 400×400 px) et légères (< 500 Ko).
- Nomme-les simplement, par exemple : `2018.jpg`, `2019.jpg`, `2025.jpg`.
- Ensuite, dans l'onglet `Legende` du Google Sheet, colonne `photo`, écris le chemin :
  `legende/2018.jpg` (ou une URL complète `https://...`).

Tant qu'aucune photo n'est renseignée, l'emoji de l'édition s'affiche à la place.
